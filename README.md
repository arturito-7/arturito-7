# Arturo Gómez Izquierdo

Full-stack developer at IPS Projects, building **MavelPoint** — a SaaS platform for the electronic music industry. BSc in Software Engineering (Complutense University of Madrid), starting an MSc in Artificial Intelligence there in September 2026.

I work across the whole stack: backend, frontend, infrastructure and testing. Day to day I integrate language models in production, build agents and spend a fair amount of time on the context they consume — including an intra- and inter-repository indexing graph so agents can find related code faster. I also taught myself Solidity, which turned into my final degree project.

Two things I care about: understanding what the model is doing instead of trusting it blindly, and shipping things that actually reach production.
